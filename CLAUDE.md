# CLAUDE.md — kitchencalc

Project instructions for Claude Code working in this repo. Inherits the ElevatedProgress
venture playbook from the parent folder's CLAUDE.md.

## What this is

A zero-dependency static-site generator. `generate.js` reads `data/kitchen.json` + `assets/`
and writes ~160 HTML pages into `public/`. It's an SEO-driven, AdSense-monetized cooking
conversion site: "how many tablespoons in ⅓ cup", "grams in a cup of flour", "350°F to °C",
butter-stick math — plus an interactive recipe scaler and converters. Target:
https://kitchen.elevatedprogress.com/. Audience is general/US consumers — clean, fast, light.

## Deploy — just push

`git push` to `main` is the deploy — GitHub Actions (`.github/workflows/deploy.yml`) runs
the generator and publishes to Pages.

- **Never manually build and commit output.** `public/` is git-ignored build output.
- **Never hand-edit anything in `public/`.**
- Commit as the neutral identity, NOT a personal name:
  `git -c user.name="kitchencalc" -c user.email="kitchencalc@users.noreply.github.com" commit …`

## Local build / preview

```
node generate.js     # writes ./public
node server.js       # preview at http://localhost:5058
```

## Adding pages

Edit `data/kitchen.json`: `cupFractions` (each needs v/slug/disp/word), `ingredients`
(gPerCup drives all gram pages — use standard baking-reference densities, e.g. King Arthur
values), `fToC`/`cToF` temperature lists, `cupsInOz`, `bigUnits`. Unit constants live at the
top of `generate.js` and in `assets/tool.js` — keep them in sync.

**Accuracy rules:** US customary units everywhere (cup = 236.6 ml, fl oz = 29.57 ml);
fluid-vs-weight-ounce distinction must stay explicit on ounce pages; thirds of a cup render
as "5 tablespoons + 1 teaspoon" style, never "5.33 tablespoons".

## Don't break these (generated by generate.js, must keep serving)

- `ads.txt` + the AdSense loader in `<head>` — publisher `ca-pub-5580575158570188`.
- `sitemap.xml`, `robots.txt`, `.nojekyll`, `CNAME` (kitchen.elevatedprogress.com).
- A Google Search Console verification file will be added once the property is verified.
